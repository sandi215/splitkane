## Concept

**SplitKane** — a zero-backend expense splitter (vanilla JS, no deps, no
login) + a Kane CLI verify loop. The pitch: agents write code fast but
can't check their own work; Kane drives this app in real Chrome and
proves the split math ($10 / 3 = $3.34+$3.33+$3.33, never $9.99).
`npm run ship` refuses unless Kane passed <24h ago. Hits all 3 judging
bars + all 4 dimensions (Ships / Verified / Closed loop / Craft).
